# ORBIT

A complete eight-page creative workspace. Open **index.html** in a modern browser to begin. No installation, build step, account, or network connection is required.

## Explore

- **Overview:** a live summary of projects, ideas, focus time, and recent activity.
- **Project board:** editable projects, categories, priorities, dates, drag-and-drop columns, accessible status menus, filters, and a timeline.
- **Discovery atlas:** six illustrated fictional worlds with creative prompts, saved collections, and direct project/note creation.
- **Notebook:** searchable notes, tags, immediate saving, safe Markdown previews, and Markdown downloads.
- **Creative lab:** four animated generative patterns, density/movement/expansion controls, four palettes, randomized variations, PNG export, and saved study notes.
- **Focus room:** configurable timer, breaks, pause/reset, synthesized ambience, and completed session tracking. Timers continue across navigation and reconcile when you revisit the focus page.
- **Insights:** actual workspace metrics, a seven-day focus chart, a 91-day activity grid, and CSV export.
- **Preferences:** name, light/dark appearance, reduced motion, full JSON backup export/import with validation, and confirmed reset.

Use **Ctrl K** (or **Command K**) to search pages, projects, and notes. Use Tab to navigate and Escape to close dialogs.

## Your data

Starter content is included. Everything you add lives in your browser's local storage. It does not sync across browsers or devices. Export a JSON backup in Preferences to keep a copy or move your workspace. Import and reset require confirmation before replacing your data.

For the most consistent persistence, serve this folder through any static web server or use the hosted version. Browsers may isolate local file storage differently, especially in private browsing. HTML files, styles, JavaScript, and SVG assets are all included.

Artwork and ambient sound are generated locally. The atlas is fictional. There are no external fonts, tracking scripts, third-party libraries, or external image dependencies.
